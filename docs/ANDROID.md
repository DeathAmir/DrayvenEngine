# Android export

Android export requires a complete Android toolchain. Set either `ANDROID_SDK_ROOT` or `ANDROID_HOME`, install the Android SDK, NDK and CMake, then run:

```bash
drayvenc build MyGame.drayven --target android
```

The exporter refuses to continue when the SDK or NDK cannot be discovered. Native C++ builds use the NDK CMake toolchain. The generated staging directory lives in `Build/Android`.

A production APK/AAB also needs the SDL Android Gradle/AAR integration and signing configuration. Those are not generated by the current exporter yet; project secrets/signing keys should stay outside the repository.
